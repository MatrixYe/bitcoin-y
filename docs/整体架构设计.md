
# 系统架构设计
逻辑依靠原版v0.3.19，但结构重写。


## 功能区分
```text
miner.rs         只负责构造候选块、搜索 nonce
p2p.rs           只负责网络收发
validation.rs    负责 ProcessBlock / AcceptBlock / ConnectBlock
chain.rs         负责 BlockTree 和 best chain 切换
mempool.rs       负责交易池

```


## 多线程与消息驱动

```text

主验证线程 / event loop：
  唯一持有 NodeState
  接收 NodeEvent

P2P 线程：
  收到 block/tx 后发送 NodeEvent::BlockReceived / TxReceived

挖矿线程：
  拿一个 MiningWork 快照搜索 nonce
  找到后发送 NodeEvent::BlockMined

存储线程：
  负责异步写盘，或者由验证线程同步调用 store trait

```


## 存储层
```text
blocks           完整区块数据
block_index      区块头、height、chain_work、status、prev
active_chain     height -> hash
chain_state      best_hash、best_height、best_chain_work
utxos            当前 UTXO 集
mempool          纯内存模式
wallet keys      钱包私钥、公钥、keypool

```
