# 挖矿流程纲要

## 原版v0.3.19的流程

1. `GenerateBitcoins()`打开挖矿开关，按 CPU/配置启动`ThreadBitcoinMiner`。
2. 每个线程进入`BitcoinMiner()`，设置低优先级，检测 SSE 2，创建本线程`CReserveKey`、`nExtraNonce`。
3. 等待有节点连接且不处于初始区块下载。
4. 记录`nTransactionsUpdatedLast`和当前`pindexBest`。
5. `CreateNewBlock()`取得当前最佳前序块`pindexPrev`。
6. 创建空`CBlock`。
7. 创建 coinbase 骨架：null prevout，输出脚本为预留公钥`OP_CHECKSIG`，金额暂未填。
8. 把 coinbase 作为`vtx[0]`。
9. 遍历内存池，跳过 coinbase 和非 final 交易。
10. 计算交易优先级，处理内存池内依赖关系。
11. 按优先级尝试加入交易，检查块大小、sigops、最低手续费。
12. 用`ConnectInputs(…, fMiner=true, …)`试连接交易，成功则加入候选块并累计`nFees`。
13. 用`GetBlockValue(height, nFees)`计算`subsidy + fees`，写入 coinbase 输出金额。
14. 初次设置区块头：`hashPrevBlock`、`hashMerkleRoot`、`nTime`、`nBits`、`nNonce=0`。
15. 回到`BitcoinMiner()`，调用`IncrementExtraNonce()`修改 coinbase`scriptSig`。
16. 因 coinbase 改变，重新计算`hashMerkleRoot`。
17. 调用`FormatHashBuffers()`预构建 SHA-256 buffer 和 midstate。
18. 在扫描循环中递增 nonce，执行 double-SHA 256。
19. 扫描函数先做快速预筛选，外层再做`hash <= target`完整判断。
20. 命中后写回真实`pblock->nNonce`，调用`CheckWork()`。
21. `CheckWork()`检查是否 stale，保留 coinbase key，并调用`ProcessBlock(NULL, pblock)`。
22. `ProcessBlock()`按普通新区块流程校验、写盘、接入主链并中继。
23. 如果没命中，则根据关闭、停止挖矿、节点断开、nonce 空间接近耗尽、内存池更新、最佳链变化等条件退出当前候选块并重建。
