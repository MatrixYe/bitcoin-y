# 挖矿的核心流程

1. 挖矿前的准备工作，线程、钱包等
2. 获取最佳前序区块
3. 创建待选空区块
4. 创建初始 `coinbase` 交易并添加到区块中
5. 从内存池中收集交易,统计累计手续费
6. 计算区块补贴
7. 计算区块价值，更新 coinbase 交易
8. 设置区块头字段`hashPrevBlock`:前序区块哈希
9. 计算并设置区块头字段`hashMerkleRoot`:交易集的默克尔树根
10. 计算并设置区块头字段 `nTime`:时间戳
11. 计算并设置区块头字段 `nBits`:难度指标压缩值
12. 设置nonce起始点 `nNonce=0`
13. 计算并设置nonce拓展空间 `nExtraNonce`
14. 预构建哈希缓冲区
15. 循环扫描 nonce
16. 工作量检测
17. 检查是否需要中断挖矿，或者重建区块
18. 每个几秒更新时间戳
